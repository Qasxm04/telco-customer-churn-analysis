# Data Dictionary

| Field | Description |
|---|---|
| `customerID` | Unique customer identifier |
| `gender` | Customer gender |
| `SeniorCitizen` | Whether the customer is a senior citizen (1/0) |
| `Partner` | Whether the customer has a partner |
| `Dependents` | Whether the customer has dependents |
| `tenure` | Number of months the customer has stayed |
| `PhoneService` | Whether phone service is active |
| `MultipleLines` | Whether multiple phone lines are active |
| `InternetService` | Internet service type: DSL, fibre optic, or none |
| `OnlineSecurity` | Whether online security is active |
| `OnlineBackup` | Whether online backup is active |
| `DeviceProtection` | Whether device protection is active |
| `TechSupport` | Whether technical support is active |
| `StreamingTV` | Whether streaming TV is active |
| `StreamingMovies` | Whether streaming movies are active |
| `Contract` | Contract type |
| `PaperlessBilling` | Whether paperless billing is enabled |
| `PaymentMethod` | Customer payment method |
| `MonthlyCharges` | Monthly amount charged |
| `TotalCharges` | Total amount charged over the relationship |
| `Churn` | Actual churn outcome: Yes or No |
| `PredictedChurnLabel` | Model-generated churn prediction |
| `ChurnProbability` | Model-estimated probability of churn |
